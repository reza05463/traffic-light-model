# مدل زمان‌دار چراغ راهنمایی

این مدل را برای تمرین شبکه‌های پتری زمان‌دار در دانشگاه با **CPN Tools** شروع کردم. فایل اصلی را همراه توضیح بخش‌های فعلی و کارهای باقی‌مانده در این مخزن گذاشته‌ام.

**وضعیت پروژه: ناکامل.**

## باز کردن مدل

فایل [traffic-light.cpn](model/traffic-light.cpn) را در نسخه سازگار CPN Tools باز کنید. نسخه ثبت‌شده در فایل، 4.0.1 است. 

صفحه `trafficlight` سه مکان، پنج گذار و هشت کمان دارد. مجموعه‌رنگ زمان‌دار `STATE` شامل `Green`، `Yellow` و `Red` است. در یکی از چرخه‌ها، تأخیر توکن‌های خروجی به‌ترتیب ۱۰، ۳ و ۲ واحد زمان مدل است.

این تأخیرها به‌تنهایی مدت کامل هر فاز را مشخص نمی‌کنند و هنوز معادل آن‌ها بر حسب ثانیه تعیین نشده است.

## بخش‌هایی که هنوز نیاز به بررسی دارند

- شاخه عمودی فقط گذار سبز به زرد را دارد؛ با نشان‌گذاری اولیه قرمز، چرخه کامل نمی‌شود.
- بخش `mainState` و `changecoller`، از جمله عبارت کمان دوطرفه، نیاز به بازبینی دارد.
- هنوز بررسی نشده که سبز شدن هم‌زمان مسیرهای متقاطع ناممکن باشد.
- گزارش شبیه‌سازی یا تحلیل فضای حالت در مخزن ندارم.

## ادامه کار

1. نوع و عبارت همه کمان‌ها در CPN Tools بررسی شود.
2. هر دو جهت حرکت و یک حالت فاصله ایمنی با چراغ قرمز برای همه مسیرها تعریف شوند.
3. معنی واحد زمان و نشان‌گذاری اولیه مشخص شود.
4. دسترس‌ناپذیری حالت سبز هم‌زمان مسیرهای متقاطع و نبود بن‌بست بررسی شود.
5. رد اجرای شبیه‌سازی و آمار فضای حالت ذخیره شوند.

ساختار XML فایل بررسی شده است، اما برای این نسخه منتشرشده، **شبیه‌سازی CPN Tools اجرا نشده است**. مدل صرفا برای اهداف آموزشی و آشنایی با نرم افزار طراحی و تولید شده و توانایی اجرایی ندارد.
